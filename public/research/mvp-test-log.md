# Deployed MVP usability test log

Test the deployed MVP: https://dist-pink-one-67.vercel.app/

## Task
“Imagine you completed a core home service recently. Choose only needs that genuinely matter in your household and create the 90-day plan.”

## For each target user, record
- Anonymous participant ID
- Target segment and completed UC category
- Household role
- Returner or non-returner
- Start time and completion time
- Number of needs selected
- Whether each need was genuinely needed
- Whether timing was understood
- Whether any task felt unnecessary or urgent
- Task success or failure
- Expectation of usefulness
- Exact usability issue
- Quote with identifiers removed
- Proposed change

## Minimum pass criteria
- At least 3 target-segment users
- Every user completes or clearly abandons the real task
- No account, booking or UC/partner action is taken
- Documented results and a next-iteration change
